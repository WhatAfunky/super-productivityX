3 · How it appears

Option 1 · "Pop out" button in focus mode
Work on: Storyboard
24:12
One click: the main window hides, the widget shows in its focus layout. "Open main window" on the widget brings it back.
Option 2 · Automatic
While a focus session runs and you hide/minimise/close the main window, the widget appears on its own (today's Task-widget behaviour, now in focus layout). Showing the main window hides it again — unless Always show task widget is on.
Can be combined with option 1.

4 · Decisions for you

1. Layout: A compact bar, B card with screenshot — or A by default and resizable into B (the widget is already resizable; it could switch layout by size).
2. How it appears: option 1 (pop-out button), option 2 (automatic), or both.
3. Clicking the thumbnail: nothing, or open the full screenshot?
4. Fixed by the decisions so far:
  • All controls: pause/resume, log a break (Flowtime), complete, cancel, open main window.
  • Desktop app only (Electron); uses the existing Task widget settings (enable, always show, opacity).
  • The main window keeps running hidden — quitting the app still ends everything.
